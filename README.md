# 序页 · 白底黑字与多彩点缀

这是带侧边分类、常用入口和资源分组的序页首页，使用纯白背景、深灰正文和中性灰强调色，增大文字与阅读间距。项目位于 D:\夹\开发\GPT\导航1。

直接打开 index.html 即可使用，无需安装框架或后端。

- index.html：页面结构与自定义导航窗口。
- style.css：多彩点缀、阅读排版及响应式布局。
- app.js：搜索、收藏、自定义网址和本地保存。
- bookmarks-data.js：按域名合并后的 23 类、267 个导航网址、简介和用途标签。

## 网站扩充（2026-11-17）

新增 107 个网站，当前共 267 个网址、23 个分类。AI 工具共 67 个，分为对话与搜索、编程、图片、视频、音频与音乐、写作与研究、接口与平台七类。原有 AI 工具保留收藏标识，并按用途调整分类。

首页 AI 快捷标签可直接筛选分类；搜索支持网站名称、简介、网址、分类和用途标签，例如“文生图”“配音”“本地模型”。单分类采用铺满内容区的响应式网格，紧凑模式隐藏简介和用途标签。

新增预置网址按主域名去重。产品功能、收费、登录要求和可访问地区以各网站当前说明为准。

点击“添加网址”或“自定义导航”，可以添加、编辑和删除自己的网址，也能输入新分类。自定义网址和收藏保存在当前浏览器，刷新后保留；更换浏览器、页面域名或清理浏览器存储会使用不同的数据。可通过“导出备份”下载自定义网址清单。

网站图标从目标源站的 /favicon.ico 加载；加载失败时使用文字标识。

点击顶部“我的导航”或当前分类可清除筛选并返回全部资源。按 / 聚焦搜索，按 Escape 清空搜索。紧凑视图支持本地记忆。

本次从 218 条书签合并得到 113 个独立域名，与预置网站重合 5 个，新增 108 个。预置列表内重复域名也已合并，最终共 160 个网址、18 个分类。简介根据网页公开信息与书签主题整理；无法访问的网站依据原书签推断，内网入口需在对应网络访问。相同主域名只保留一个代表入口，原有自定义网址与收藏的浏览器存储方式不变。
