# 序页 · Title Page

**为日常工作、创作与探索而设计的个人网址导航。**

**在线演示：[tp.infoto.top](http://tp.infoto.top/)**

序页将 AI 应用、开发工具、设计素材、技术社区与常用服务整理到一个清晰的工作入口。白色背景、黑色正文与多彩分类搭配，结合即时搜索、收藏和自定义导航，让常用资源更容易找到。

使用 HTML、CSS 与原生 JavaScript 构建，无需安装依赖、运行构建工具或配置后端。可直接打开，也可部署到 GitHub Pages、Nginx 等静态托管环境。

## 核心功能

### 分类导航与即时搜索

- 按主题浏览网站，支持切换到单个分类查看。
- 搜索网站名称、网址、简介、分类及用途标签，输入后即时过滤。
- 单分类视图使用响应式网格，充分利用内容区域。
- 支持紧凑视图，适合需要更高信息密度的使用场景。
- 按 `/` 聚焦搜索，按 `Escape` 清空搜索。

### AI 工具专题

通过首页快捷标签进入不同用途的 AI 分类，支持搜索“文生图”“配音”“本地模型”等关键词。

| 方向 | 代表网站 |
| --- | --- |
| 对话与搜索 | ChatGPT、Claude、DeepSeek、Kimi、Perplexity |
| 编程 | Cursor、Windsurf、OpenCode、Replit、Bolt |
| 图片 | Midjourney、Ideogram、Recraft、ComfyUI、LiblibAI |
| 视频 | Runway、可灵 AI、海螺 AI、Vidu、Pika |
| 音频与音乐 | Suno、Udio、ElevenLabs、AIVA、Descript |
| 写作与研究 | Gamma、Napkin AI、Consensus、Elicit、DeepL |
| 接口与平台 | Hugging Face、OpenRouter、硅基流动、Ollama、LM Studio |

### 个人收藏与自定义导航

- 收藏常用网站，快速访问个人常用入口。
- 通过可视化窗口添加、编辑或删除自定义网址，并指定或新建分类。
- 收藏、自定义网址及视图偏好保存在当前浏览器，刷新后保留。
- 支持将自定义网址导出为 JSON 文件。
- 从目标网站加载 favicon；加载失败时显示文字标识。

### 轻量交互与响应式布局

页面提供入场过渡、悬停反馈、收藏反馈、滚动进度和返回顶部等交互。可切换静态模式，并适配系统的减少动态效果偏好。

布局随屏幕尺寸调整，适合桌面浏览器、平板和手机访问。

## 快速开始

### 直接打开

下载或克隆仓库后，在浏览器中打开 `index.html` 即可使用。

```bash
git clone https://github.com/jchenren/Title-Page.git
cd Title-Page
```

### 本地服务

如果已安装 Python 3，也可以在项目根目录启动静态服务：

```bash
python -m http.server 8080 --bind 127.0.0.1
```

访问 [http://127.0.0.1:8080/](http://127.0.0.1:8080/)。

建议日常使用固定的网址和端口，以保持浏览器本地数据的存储位置一致。

## 部署

### GitHub Pages

1. 将项目文件提交到 GitHub 仓库。
2. 打开仓库的 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**。
4. 选择存放项目文件的分支，将目录设为 **/(root)** 并保存。
5. 等待部署完成，访问 GitHub Pages 提供的网址。

项目使用相对资源路径，可部署在 GitHub Pages 的仓库子路径下，无需构建命令。

### Nginx

将项目文件复制到静态站点目录，例如 `/var/www/title-page`，并按实际域名调整配置：

```nginx
server {
    listen 80;
    server_name nav.example.com;

    root /var/www/title-page;
    index index.html;

    location / {
        try_files $uri $uri/ =404;
    }
}
```

检查配置后重新加载 Nginx；如需 HTTPS，可通过现有证书或证书管理工具配置。

## 内容维护

### 在页面中维护个人网址

点击“添加网址”或“自定义导航”，填写网站信息并保存。此方式修改的是当前浏览器中的个人数据，不会更改仓库文件或其他访客的导航内容。

### 维护预置网站

所有访客共享的预置内容位于 `bookmarks-data.js`。按照现有分类结构增加或调整网站记录，网站记录的字段顺序为：

```javascript
[
  'example-site',
  '示例网站',
  'https://example.com/',
  '简洁说明网站的主要用途',
  'E',
  'blue',
  ['用途标签', '关键词']
]
```

依次为网站标识、名称、网址、简介、备用文字图标、配色及用途标签。标签为可选项，可用于搜索；AI 分类还会显示用途标签。

维护时请保持分类和网站标识唯一，优先按主域名合并重复入口，并使用明确、简短的用途说明。修改后刷新页面即可查看，部署环境需同步更新静态文件。

## 数据与使用说明

- 当前版本为纯静态应用，个人设置使用浏览器 `localStorage` 保存；未提供账号登录、后台管理、云端同步或跨设备同步。
- 本地数据按浏览器及站点来源区分。更换协议、域名或端口，以及清除浏览器站点数据，可能导致无法读取原有设置；直接打开本地文件时，存储行为还取决于浏览器。
- “导出备份”目前仅导出自定义网址，不包含收藏和界面偏好，暂未提供导入界面。
- 搜索在浏览器本地执行。网站图标会向对应网站的 `/favicon.ico` 发起请求，加载结果取决于目标网站及网络环境。
- 预置内容包含从个人书签整理的云文档、工作入口及内网地址。公开部署前，请检查并移除不适合公开的条目；内网资源需要在对应网络中访问。
- 第三方网站的功能、收费、账号要求和可访问地区，以各网站当前说明为准。
